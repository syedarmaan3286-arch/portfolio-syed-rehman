# Syed Rehman Yousuf - IT Support Engineer Portfolio 🚀

A premium, interactive personal portfolio website designed for an IT Support Engineer. This project showcases professional experience, technical skills, and certifications using modern web design techniques.

## Features ✨
- **Premium Dark Theme:** Sleek dark navy background (`#050a15`) with vibrant cyan/blue tech accents.
- **Dynamic Animations:** Features smooth scrolling, a simulated typing effect for the hero section, and scroll-reveal transitions.
- **Glassmorphism Design:** Modern translucent cards and panels with soft glowing effects.
- **Fully Responsive:** Adapts beautifully across desktop, tablet, and mobile devices.

## Tech Stack 🛠️
- **HTML5** (Semantic structure)
- **CSS3** (Custom properties, Flexbox/Grid, Animations)
- **Vanilla JavaScript** (Interactivity and DOM manipulation)

## Viewing the Project 💻
This is a static web page. No servers or build tools are required.
1. Download or clone this repository.
2. Locate the `index.html` file.
3. **Double-click** `index.html` to open it in your default web browser.

## Customization 🎨
- **Colors:** You can change the primary colors by modifying the CSS variables located at the top of `styles.css`.
- **Content:** Open `index.html` to update your experience, skills tags, and contact information.
